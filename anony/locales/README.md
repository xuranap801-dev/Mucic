# Available Languages

This directory contains the available translations for **Mikasa Music**.

| Code | Language |
|---|---|
| ar | Arabic |
| de | German |
| en | English |
| es | Spanish |
| fr | French |
| hi | Hindi |
| ja | Japanese |
| my | Burmese |
| pa | Punjabi |
| pt | Portuguese |
| ru | Russian |
| tr | Turkish |
| zh | Chinese |

To add or improve a translation, update the relevant locale JSON file and keep all placeholders intact. Configure your own support links through the environment variables instead of hardcoding personal identities.
